The method projects the original source and target into XY, subtracts them, calculates squared distance, rejects values outside the beam object's squared bounds `+0x34` and `+0x38`, and compares `acos(dot(normalizedForward, normalizedDelta))` to the native `+0x40` angular cutoff.
