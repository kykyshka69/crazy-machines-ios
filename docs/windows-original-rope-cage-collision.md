# Original Windows rope cage: opening and physical Catch/Test point

The user's original game mesh `rope_cage.UCM` is a 11,740-byte UCM version2 file (SHA-256 `402c793b0d334fc8ffa2f14cef3e726dadb9e7c665929c7ddf692d81c6d591f4`). Its measured vertices extend from X/Z ±0.32006, Y −0.20068 to +0.43542. The **upper handle** contributes the highest Y vertices. The visible mouth rim at Y≈0.255..0.283 has a radius ≈0.08..0.11, while lower hoops at Y≈−0.176 have radius ≈0.30. There are ten instances of `tmo_rope_cage` in the owner's 102 level CML scenes, including four GOAL-marked cages, each with a separately authored `3DO to_dummy_bounding` Catch/Test helper positioned at its own POSREL.

The previous SceneKit `SCNPhysicsShape.ShapeType.convexHull` built over **all cage mesh vertices including the decorative upper handle** created a solid collision roof, preventing balls from entering the real container and reaching the native Win32 GOAL point. The existing `CMOriginalWindowsCatchRadius` correctly uses native strict distance under 0.1 but needs attainable physical geometry.

`CMOriginalCageCollisionProxy` now builds three separate, collision-only shapes from the imported cage mesh's measured bounds: a **bottom** and **two tapered walls**. The side rotation follows the original lower/wider and upper/narrower cage rings; its mouth remains open and does not include the original handle as a lid. SceneKit constructs the compound shape using the imported 3DO-to-owner transforms, respecting original POSREL, ROTREL and mirror/scale. The genuine UCM remains unchanged for rendering. This is a bounded physically plausible **iOS collider approximation**, not a reverse-engineered Win32 rigid-body solver. Nothing is manually teleported or awarded a GOAL; it only removes an accidental impossible collision.

The native Windows GOAL channel for both cages and buckets is still checked independently on the exact original `to_dummy_bounding` target when the original `tmo_ball_*` center is strictly within radius 0.1. Portable and CI tests cover the cage's measured original bounds and open-mouth geometry. Full 102-level physics and user win parity remain unverified.
