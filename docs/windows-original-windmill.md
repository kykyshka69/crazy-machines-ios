# Native Windows windmill GOAL: original level 34

The user's original PE32 has an authentic `tmo_windmill` callback at `0x44F3B1..0x44F4D7`, using `tmo_windmill_wheel` as a physically simulated child. The native GOAL branch reads a float from its wheel physics structure at **+0xE0**, calls `0x4270D0` (absolute float), compares it with the native float constant `0x4E737C = 0.30000001192092896`, and only if the absolute value is strictly **greater** calls `0x44B460` at `0x44F4D2`.

Original PC puzzle 34 contains a GOAL-marked windmill with an actual child wheel, mirrored SCAL (-1,1,1), along with a GOAL-marked belt flag. The iOS SceneKit renderer observes the **actual corresponding child wheel physics body** through exact parent hierarchy instead of starting a nonexistent fan when the game is played. When it rotates beyond the native threshold in prototype physics, the same original owner ID can dispatch the GOAL channel once. The threshold is verified Win32; mapping SceneKit angular velocity to native +0xE0, wind forces, gear/friction and belt flag events are still incomplete and must be verified against Windows behavior. No fake wind force or auto-spin has been added.
